# Ombracrypt Quick Start Guide

This guide provides step-by-step instructions for securing and recovering data using Ombracrypt's hybrid post-quantum encryption vault.

---

## Encrypting Data

### Step 1: Configure Cryptographic Settings & Passwords
1. Open the Ombracrypt application.
2. Under **Cipher Algorithm**, select your symmetric engine (`AES-256-GCM` or `XChaCha20-Poly1305`).
3. Under **KEM Algorithm**, select your hybrid post-quantum profile:
   - **IETF X-Wing:** Standard hybrid (`ML-KEM-768` + `X25519`).
   - **Cypherpunk:** High-security profile (`ML-KEM-1024` + `X25519`).
4. Enter and confirm a strong **Master Password**.
5. *(Optional)* Expand **Advanced Security Options** to configure a **Deception Passcode** for duress protection.

### Step 2: Select the Target Directory
1. Click **Encrypt Folder** to launch your native system directory picker.
2. Navigate to and select the folder you wish to protect.

### Step 3: Verify Path and Lock Vault
1. Confirm that the displayed target path points strictly to the intended folder.
2. Click **Lock Vault** to initiate compression and in-memory chunked streaming encryption.
3. Wait for the operation to reach 100%.

### Step 4: Verification and Key Separation
Once completed, the application confirms:  
`Operation Successful: Vault securely locked (.obv) and Quantum Key (.obk) generated.`

Check the parent directory of your source folder. Two linked files have been generated:
- **`[FolderName].obv` (Encrypted Vault):** Contains the authenticated ciphertext payload. Safe to backup, sync to cloud storage, or transmit over untrusted channels.
- **`[FolderName].obk` (Quantum Key):** Contains the wrapped hybrid private key material.

> **Security Mandate:** Immediately move the `.obk` file to a physically separate, offline medium (such as an encrypted, air-gapped USB flash drive). Without both the `.obk` file and your master password, the vault cannot be decrypted by any party.

## Decrypting Data

### Step 1: Load Target Files
1. Switch to the **Decrypt Vault** view in the application.
2. Under **Vault File**, browse to and select your encrypted `.obv` vault.
3. Under **Key File**, browse to and select the corresponding `.obk` key file.

### Step 2: Confirm Paths and Authenticate
1. Verify that the displayed file paths match the expected vault and key pair.
2. Enter your standard **Master Password**.

### Step 3: Execute Restoration
1. Click **Unlock Vault**.
2. The engine performs authenticated AEAD streaming verification into an isolated staging folder.
3. Upon successful integrity verification, the decrypted directory is atomically published directly into the directory containing your `.obv` file.

## Coercion Defense: Deception Passcode (Duress Code)

The Deception Passcode is a specialized cryptographic zeroization failsafe designed for situations where an operator is under physical duress or coercion.

### How It Works

1. **Activation:** If forced to unlock your vault by an adversary, open the normal decryption screen.
2. **Credential Substitution:** When prompted for your credentials, enter your pre-configured **Deception Passcode** instead of the actual Master Password.
3. **Plausible Error Display:** The interface intentionally displays a generic "password mismatch" error, mimicking an ordinary mistyped character.
4. **Silent Key Scrambling:** In the background, the cryptographic engine immediately overwrites the internal private key payload within the targeted `.obk` file with random noise generated by a cryptographically secure pseudorandom number generator (CSPRNG). File size and outer structure remain intact.
5. **Irreversible Neutralization:** Because Ombracrypt relies on a split-key architecture, zeroizing the `.obk` payload breaks the cryptographic chain permanently. The `.obv` vault becomes mathematically unrecoverable to all parties, including yourself and the attacker.

> **Warning:** Deception zeroization executes immediately and cannot be undone. Trigger this mechanism only during genuine emergencies.
